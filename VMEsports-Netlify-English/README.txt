VM Esports - Netlify upload

This is a static Netlify version translated from the supplied ASP.NET MVC source.
Open index.html to preview. Upload this whole folder to https://app.netlify.com/drop.
Player profiles use profile.html?id=1 through profile.html?id=12.

Netlify cannot run the original C# MVC app itself. This copy preserves the pages, roster data, links and visual style as static web pages.

Only five player photos existed in the supplied project: Noxxie, OneShoT, Divine, Spike and Oris. Add the remaining player JPGs to assets/images/players using the filenames listed in site.js to show their real photos.
